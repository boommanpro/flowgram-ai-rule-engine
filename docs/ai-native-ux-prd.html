1设计原则 & 核心目标

本次重构是「用户体验的重新编排」，不新增任何功能模块。所有现有 API、工具执行器、画布引擎均保持原样。

🎯

主模式自适应

根据用户当前场景，自动进入最贴合的模式：写工作流→画布为主；提问+生成→对话为主；边看边改→Copilot 侧栏。

🔗

全链路可视

任一条消息都能回溯：CreatePlan 步骤、tool call、tool result、debug entry、画布节点操作。跳转保持相同语义。

🧩

单一事实源

会话、消息、调试条目、节点等数据不重复维护，三模式共享同一 AgentContext + CanvasContext 数据源。

⚡️

零思考切换

模式切换仅改变「布局容器」，不丢失状态：输入框草稿、消息滚动位置、plan 折叠态、debug 聚焦全部保留。

🪟

画布永不缺席

即便是「对话为主」模式，画布也以内嵌/浮窗方式常驻，用户永远能"看到正在发生的结构"而不是纯文字想象。

💬

ChatGPT 式对话流

对话流式渲染、SSE token 进度、::options 快捷选项、右侧 assistant 消息 + tool call 卡片 / tool result 卡片。对话永远是视觉主角。

4模式切换机制（入口、快捷键、持久化、过渡）

切换仅改变"外壳容器"，所有内部状态完全不销毁（保证体验顺滑）。

  • 顶栏三段式切换器（A / B / C）：所有模式的顶栏左上角均渲染相同的切换 Pill，点击即时生效。
  • 全局快捷键：Ctrl / ⌘ + 1 画布为主 · Ctrl / ⌘ + 2 对话为主 · Ctrl / ⌘ + 3 Copilot 侧栏
  • 智能入口判断： 路由 /editor 无当前会话 → 默认 A（画布为主）； 新建会话 / 点击"AI 创建工作流" CTA → 默认 B（对话为主）； 非编辑器路由 + FAB 打开 → 默认 C（Copilot 侧栏）。
  • URL Search Param 同步：?mode=canvas | chat | copilot，刷新后仍保持。
  • localStorage 记忆：每路由类型独立记忆。Editor 路由和 Admin 路由各存一份偏好。
  • 状态保留：输入框草稿、PlanCard 折叠态、消息滚动位置、debug 面板打开态与聚焦条目、canvas 视图位置——切换时不卸载组件，纯 CSS display / grid-area 变换。
  • 过渡动画：模式切换动画 = 300ms ease 尺寸 + 120ms 面板透明度过渡，避免"刷新感"。
  • 非编辑器降级：Home / Releases / Admin 等页面只能进入 C 模式，A / B 按钮禁用且 tooltip 提示"请打开编辑器或会话审查页使用画布为主/对话为主"。

📌 切换状态对照表

🟢 A → B

画布从主区域缩小为对话右栏内嵌预览；对话从折叠抽屉变为居中主列；会话列表从 180px 浮层 → 260px 永久左栏。

🟢 A → C

Canvas 仍占满屏幕；对话主列折叠为 Copilot 420px 抽屉；内嵌画布预览关闭；FAB 行为与现状一致。

🟢 B → A

内嵌画布从右栏 380px 全屏展开为主画布；对话主列折叠进 420px 抽屉；右多功能面板关闭/折叠进 DebugPanel 抽屉。

🟢 C → A/B

Copilot 抽屉展开为 A 或 B；非编辑器路由时会先 navigate 到 /editor 再切换。

5对话为主模式 · 画布内嵌展示细则（本 PRD 最关键的体验点）

"在对话为主中也展示画布" = 非截图，非缩略图，而是同一份 Canvas 渲染实例，视觉缩小但操作完整。 这是区分"聊天机器人 / 智能工作流 Copilot"的核心体验。

  • 数据源完全一致：复用同一 FreeLayoutEditorProvider + EditorCanvasBridge，A 模式与 B 模式只改容器尺寸。不会出现"对话里的画布和真实画布不一致"。
  • 节点高亮脉冲：当 Agent 的 createNodeByType / deleteNode / addLine 等 canvas 工具被执行时， 对应 node id 触发 2.4s 的蓝色脉冲（box-shadow + scale），让对话流用户"看着 AI 正在对哪里动手"。
  • 自动 FitView：每一次 canvas 写操作（新增节点 / 连线 / 删除）之后，自动 fitView(padding=60)；用户主动滚动画布后 3s 内不再抢占视图。
  • 画布工具栏（迷你版）：右上角 4 个常驻按钮 —— 🔍 FitView · ⛶ Fullscreen（临时全屏预览，Esc 退出） · 📌 Pin / Unpin 画布跟随开关 · 🔗 Jump to Canvas First（一键切换到 A 模式）
  • 尺寸调节：内嵌画布与对话之间的分隔条可拖动（默认 380px，最小 280px / 最大 760px），≥ 640px 时自动渲染 PanelManager 的属性面板（提供更完整的编辑体验）。
  • Debug 联动：点击 Debug 面板中的 canvas_tool_result → 内嵌画布定位到对应节点并高亮；与 A 模式跳转行为完全一致。
  • 运行结果同步：Test Run 结果面板在 A/B 两个模式共享同一个实例，在哪里点运行都一样。
  • 只读保护：playground.config.readonly = false（用户可以手动调整节点），与 Canvas First 完全一致，Chat 模式不是"只读观摩"。
